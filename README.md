# 408 MindMap PWA

面向 408 计算机学科专业基础综合的知识图谱学习网站，包含数据结构、计算机组成原理、操作系统和计算机网络四门课程，共 355 个结构化节点与按考法精选的练习。

项目使用 Vite 5、Vue 3、TypeScript、Vue Router、Pinia、Dexie.js、ECharts 和 vite-plugin-pwa 构建，采用 MIT 许可证开源。

## 功能

- 四科知识图谱导航与全局搜索
- 2020—2025 年 408 真题与参考解析在线阅读
- 原卷、解析、左右对照三种阅读模式，以及题号到知识点的关联跳转
- 四科独立讲解：概念来由、机制解释、适用条件、公式与完整推导例题
- 关键结论和可展开答案的回忆自测，支持阅读后检验理解
- 每节教材/公开资料对照链接，部分节点附经核对的原文短摘和中文释义
- 结构化易错点：错法、原因、纠正方法和例题支撑
- 231 个具体考点共 332 道独立原创练习（298 选择、34 综合）；章节页只作导航，不强塞万能题
- 真题原卷保存在 PDF 中，本站原创习题不冒标真题年份；参考答案与来源明确区分
- 本机错题本、错因笔记、收藏和学习状态，成功重做保留完整历史
- 主动回忆自评与间隔复习计划；阅读不自动标记掌握，自评不混入客观题正确率
- 四科 18 个可修改输入、逐步回退的推演实验：折半查找、KMP、快速/堆排序、BFS、Dijkstra、Kruskal、Cache、分页地址变换、流水线、处理机调度、银行家、页面置换、磁盘调度、子网、CRC、GBN/SR、TCP 累计确认
- 408 大纲学习导航：四科 24 章、71 项可检查学习目标、219 个相关节点，连接全部 18 个实验，支持搜索、科目及未掌握筛选
- 纸感浅色界面、分科色彩与舒适阅读排版；系统字体、本地图标和公式字体，无新增 CDN 或远程字体依赖
- 整卷限时答题卡、刷新恢复、交卷锁定、选择题报告与综合题自评分
- 离线资源清单、PDF 大小/签名/SHA-256 校验、学习记录 JSON 导出与事务合并恢复
- 本机纠错草稿，用户自行决定是否公开发送
- IndexedDB 本地内容缓存
- Service Worker 预缓存应用及全部知识 JSON
- 真题 PDF 按年份主动下载后可离线阅读
- 支持安装为桌面或移动端 PWA
- 支持 GitHub Pages 子路径部署

## 本地开发

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

打开终端输出的地址。`127.0.0.1` 只供当前电脑使用，关闭终端后服务也会停止，不能将该地址分享给其他人。

## 构建与离线启动

```bash
npm run build
npm run start:offline
```

Windows 用户也可以双击 `start-offline.cmd`。离线服务器默认使用：

```text
http://127.0.0.1:4173/
```

浏览器不允许 `file://` 页面注册 Service Worker，因此不要直接双击 `dist/index.html`。请使用上述本地服务器，或先从公开 HTTPS 网站安装 PWA。

## PWA 离线使用

1. 第一次在联网状态下打开已部署的 HTTPS 网站。
2. 等待页面加载完成，在浏览器菜单中选择“安装应用”或“添加到主屏幕”。
3. 在“离线与备份”确认 Service Worker 已接管、355 个知识资源缓存齐全。需要读试卷时，逐年下载原卷与解析。
4. 浏览器清理网站数据、卸载应用或迁移设备可能丢失本机记录；请定期导出备份。备份不包含 PDF。

第一次从未访问过该网站的设备无法凭空获得离线资源；必须先在线加载一次，或获取包含 `dist` 的离线压缩包并运行本地服务器。

## 发布到 GitHub Pages

1. 在 GitHub 创建一个公开仓库，例如 `cs408-mindmap-pwa`。
2. 将本项目内容推送到仓库的 `main` 分支。
3. 打开仓库 `Settings → Pages`，将 Source 设为 **GitHub Actions**。
4. 推送后，`.github/workflows/deploy-pages.yml` 会自动校验、构建并发布。
5. 发布地址通常为 `https://你的用户名.github.io/仓库名/`。

公开仓库提供源码，GitHub Pages 提供可分享网站，两者职责不同。代码更新后再次推送，网站会自动重新部署。

## 内容维护

```bash
npm run content:validate
npm run content:refresh
npm run questions:refresh
npm run content:generate
```

知识文件位于 `src/content/{ds,cs,os,net}`。正文在 `scripts/editorial/{ds,cs,os,net}.mjs` 独立维护；`content:refresh` 只更新正文，保留易错清单和习题。练习在 `scripts/question-bank/{ds,cs,os,net}.mjs` 独立维护，`questions:refresh` 只更新习题、校验正文及易错清单未变。`content:generate` 重建目录时同样使用独立讲解与新题库，不回退到旧万能模板。

在线状态下详情页会优先获取带哈希的最新 JSON，并回写 Dexie 供离线访问。若未来发布无法兼容旧本地数据的全量内容升级，应在 `src/db/db.ts` 新增数据库版本与一次性迁移，避免已访问节点长期命中旧缓存。

内容校验检查全节点覆盖、叶子节点例题、回忆问题、教材来源、引用链接、公式实际解析、练习重复/模板与题号，还逐一核验 12 份 PDF 哈希及答案表分值。

## 测试与自测说明

```bash
npm run test
npm run verify
```

单元/组件测试覆盖 IndexedDB 并发与回滚、备份合并和输入校验、公式选项、算法轨迹、考试截止/恢复与跨年份隔离。自动发布工作流必须通过这些测试。Vite 5 按原技术约束保留；开发服务仅绑定本机，不要向公网暴露开发或测试服务器。

本轮完整回归为 13 个测试文件、536 项用例，另验证本地根路径与 `/408review/` 子路径的生产构建。新增回归覆盖 18 个默认实验、独立算法边界、数值输入编辑、非法输入后移除旧状态、策略切换、目录与大纲链接、进度读取及筛选；以组件测试确认交互，不只测试纯函数。浏览器实测包含输入更改后锁定旧轨迹、逐步推进/回退、CRC 验算、大纲检索跳转、考试刷新恢复、取消交卷、确认锁定和自评分清空。390 px 窄屏下首页、实验、大纲、知识点和离线页无文档级横向溢出，矮窗口目录仍可滚动；不是所有真实手机和浏览器均已验收，测试通过也不代表绝对无缺陷。

大纲版本须区分：已核验 [2027 年高教社官方出版书目](https://xuanshu.hep.com.cn/front/book/findBookDetails?bookId=6aa97a0be119ac9729dd09ea)，但该页面没有公开章节或正文；本站独立导航参照 [2025 年高校公开附件](https://www.uwh.edu.cn/jkxy/detail/882/11591.html)并交叉核对出版社目录，不冒充 2027 原文。已标明 24 项待补充内容；有效关联不表示覆盖全部大纲。本站导航可离线，外部大纲 PDF 与出版机构入口需要联网，未经授权的完整大纲不托管在本项目中。

缓存回归采用停止本站本地 HTTP 服务的方法，不更改设备网络设置：在服务不可连接时成功刷新大纲、进入尚未访问的流水线实验并重新计算、打开尚未读过的流水线知识点，以及渲染并翻页已完整下载的 2024 原卷。初次安装、跨设备分享和外部原文仍需要可访问的网络源。

已执行不强制跨主版本的依赖修复。审计仍有旧技术栈相关告警：Vite 5 / esbuild 与 Vitest 3 的开发或测试服务器不要对外开放，本站测试仅使用 CLI/jsdom、不启用 UI/API/browser server；ECharts 5 相关公告涉及的 Lines 系列及默认提示模板不在当前 Tree 图谱使用范围，自定义 tooltip 文本已按官方建议转义。后续如升级 Vite / Vitest / ECharts 主版本，应单独进行兼容与图谱视觉回归，不能宣称依赖风险为零。

2020—2024 自动核对的 200 个选择题答案来自所附第三方参考解析第 1 页，不是官方判卷。2025 回忆解析存在缺项，选择题仅允许交卷后人工对照录入，不生成虚构答案。42 个综合题满分均按本地原卷题头核对；自评分不是系统自动判分，所有题评完才显示完整总分。版本差异和核验页见 `scripts/question-bank/paper-audit.md`。

学习记录不传服务器、无账号同步；备份采用较新记录合并、同时间保留本机，不会清空已有数据。PDF Cache API 不支持跨文件事务，写失败会尽力恢复原副本并如实报告失败，重新检查清单后再重试。

当前备份导入限制为 10 MB、最多 20,000 次作答和 1,000 次考试记录；长期使用时请注意备份大小，超限文件不会写入。易错清单正文沿用已确认版本，旧外部链接只标为参考资料，不再把未经对应核验的年份题号宣称为原题出处。

构建前将旧 `dist` 可恢复地移到 `.qa/build-history`，防止 Windows 残留旧哈希文件混入预缓存。源码、PDF 原件和本机学习记录不受影响。

教材资料按原始出版页面、作者公开教材或公开标准提供对照链接；短摘标明来源与定位，本站讲解和推导例题独立编写，不标作教材原题。原始资料链接需要联网，本站正文、例题、自测与已收录的短摘保存在节点 JSON 中，可以随 PWA 离线使用。

公开题源索引：[厦门工学院 2009—2025 年 408 真题与解析汇总](https://www.xit.edu.cn/yjsfk/kyzykwtkw/list.htm)。
